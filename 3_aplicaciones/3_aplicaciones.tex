\begin{frame}{Aplicaciones}
    \begin{enumerate}
        \item Almacenar datos
        \item Almacenar artículos científicos reproducibles
        \item Hospedar páginas web (GitHub pages)
    \end{enumerate}
\end{frame}


\begin{frame}{Almacenar datos}
    Almacenar datos en GitHub podría ser tan simple como suena.
    Sencillamente para subir nuestros datos brutos. \newline

    Sin embargo podemos ver que hay repositorios con basta más 
    sofisticación, y que su función es también almacenar datos. \newline

    P. ej.: \href{https://github.com/datasets/covid-19}{https://github.com/datasets/covid-19}
\end{frame}


\begin{frame}{Artículos científicos reproducibles}
    Además de almacenar datos, ¿por qué no ya limpiar los datos, analizarlos
    y presentar los resultados dentro del mismo repositorio? \newline

    Un artículo reproducible en GitHub puede tomar muchas formas,
    pero vamos a ver un ejemplo (muy muy chorra) con un repositorio
    que encontrareis en \href{https://github.com/urtzienriquez/example_repro_paper}{https://github.com/urtzienriquez/example\_repro\_paper}
\end{frame}


\begin{frame}{Páginas web}
    Otra aplicación muy útil es el hospedaje de páginas webs.

    Las páginas suelen ser estáticas, aunque gente con conocimiento 
    (e.g. que sepan utilizar react) también puede crear 
    páginas webs dinámicas.\newline

    Vamos a ver el ejemplo más sencillo posible con un repositorio de ejemplo, 
    donde simplemente habremos depositado un archivo html. \href{https://github.com/urtzienriquez/web}{https://github.com/urtzienriquez/web}\newline

    Por otro lado, GitHub permite utilizar temas de Jekyll para hacer 
    páginas web de una forma relativamente sencilla. Podéis encontrar 
    los distintos temas aquí: \href{https://pages.github.com/themes/}{https://pages.github.com/themes/},
    e información detallada de cómo construir vuestra página web
    utilizando Travis y Jekyll aquí: \href{https://docs.github.com/en/pages/quickstart}{https://docs.github.com/en/pages/quickstart}
\end{frame}
